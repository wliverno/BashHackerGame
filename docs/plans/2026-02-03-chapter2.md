**Goal:** Add Chapter 2 (Levels 4–6) teaching `cat` with subdirectory paths and multi-file usage, `echo >` for file creation/overwrite, and `echo >>` for appending — plus a chapter-boundary transition screen between Ch1 and Ch2.

**Architecture:** All commands (`cat`, `echo`) and parser features (`>`, `>>`, pipes) already exist and are tested. Changes are: (1) new level data in `levels.js` with a `chapter` field added to all levels, (2) chapter-boundary detection added to the level-transition logic in `game.js`, (3) a chapter-complete screen added to `main.js`. Tasks follow TDD order: level win-condition tests first, then game integration, then UI (no Jest test for UI — it's jQuery Terminal CDN only).

**Tech Stack:** Vanilla ES Modules, Jest + jsdom (`node --experimental-vm-modules`), jQuery Terminal (CDN). No new dependencies.

**Test command:** `node --experimental-vm-modules node_modules/.bin/jest --no-coverage`

**Important engine detail:** `echo` does NOT add a trailing newline (matches existing tests). Level 6's `dossier.txt` is pre-seeded with a trailing `\n` so appended lines start cleanly on a new line.
